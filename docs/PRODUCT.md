# QuickApp 的产品范围

QuickApp 是系统快捷启动器：统一管理软件、文件、目录、网址和常用命令，减少重复搜索、输入命令及切换窗口的次数。Dock 是入口，搜索是发现，条目是可长期维护的启动动作。

## 本次补齐

- 统一添加与编辑：修改路径或命令时保留条目位置、稳定 ID 和自定义图标；取消不改变配置。
- 明确的目录、网址入口：打开目录直接交给系统文件管理器，不要求用户了解 `explorer` 或 `start`。
- Windows 条目快捷键：Dock 收起时也能执行；校验输入、与 Dock 和其他条目的冲突，并检查系统占用。增删、修改和配置导入后即时更新注册，所有快捷键共用一个消息线程。
- 常用命令：按原文执行，支持工作目录、CMD / PowerShell、后台运行或终端保留输出。旧配置继续后台运行，新命令默认显示终端。
- 搜索结果最多高 300，支持纵向滚动；系统应用结果只保留添加按钮。
- 配置可靠性：读取失败显示原因和重试入口，阻止默认空配置覆盖原数据。只有无法解析的 JSON 才保存为 `.broken`；共享锁等读取问题保留原文件。明确确认的配置导入可解除保护。
- 文件和目录批量添加时避免重复；复制为命令保留参数并处理路径中的空格。
- 原型只保留 `design/index.html`，通过产品入口打开各界面，共用条目和设置状态；界面及交互都作为实现参考。
- 全局唤起直接打开并聚焦搜索；记忆 Dock 沿边拖动位置，把手对齐 Dock 中心，不随把手尺寸发生偏移。

## 平台边界

Windows 支持条目全局快捷键、CMD / PowerShell 与可见终端。Linux / macOS 继续通过系统 Shell 后台执行命令，暂不提供条目全局快捷键；跨平台配置中的 Windows 专属选项保留，界面明确显示能力范围。

## 后续需求判断

优先考虑命令标签及别名、参数输入模板、执行历史与输出查看、失效路径修复。先观察真实使用频率再扩展，避免让启动操作变成表单操作。自动执行任务和工作流编排会改变产品的复杂度，应单独设计。

本机原配置有四个应用，安装版运行时路径与预期一致；普通程序、NativeAOT 和完整界面验证都可读取。备份后重新启动同一个 0.5.2 安装版，四个应用恢复，配置文件 SHA-256 完全未变。首次启动失败的触发条件尚未复现，本次增加读取失败提示、重试和防覆盖保护，不宣称已确定安装器或配置迁移的根因。
